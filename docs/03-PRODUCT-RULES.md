# 产品与选项规则

## 总原则

- 页面展示、当前选择、价格明细、PI 摘要和历史订单使用同一份选项数据。
- 用户选了什么，PI 就显示什么；未选择、已删除、旧默认值或隐藏选项不得出现在 PI。
- 删除选项时，同时清理默认值、状态初始化、价格映射、摘要映射和翻译。
- 非必选工艺默认不勾选。

## 面料

- 先选择品牌，再在该品牌内部筛选，不能混入其他品牌。
- 筛选维度为颜色、花型、克重、成分和关键词；下拉框只显示真实存在且能产生结果的选项。
- 编号格式为“面料册编号·具体编号”，例如 `6402·33731`。
- 颜色判断应综合整块面料的主要视觉颜色，不能只取单个像素。
- 白色与其他颜色组成的条纹或格纹，通常按远看占主导的非白色归类。
- 面料卡支持查看大图；面料本详情弹窗展示 PDF 全部页面和系列定位说明。

## 量体与体态

- 新客户表单必须为空，不预填身高、体重或尺寸示例。
- 公制显示 `cm/kg`；英制显示 `ft + in/lb`。
- 切换单位时姓名、体重和尺寸表位置保持稳定，只有身高输入结构发生必要变化。
- 体态登记是与四类产品并列的独立选区，并同步保存至客户档案。

## 款式

- 单击卡片只选择款式；双击图片才打开大图，并显示“双击放大图片”提示。
- 选项图片文件名与选项英文名对应。
- 西裤的裤脚、裤型和裤脚口在同一行；裤装款式按一行 10 图排版。
- 衬衫侧缝工艺、袖山意式碎折、错位上袖、鸡爪扣钉和礼服打条为非必选。
- 刺绣文字、字体、位置、上传图案和自由备注都必须进入 PI。

## PI

PI 每行至少包括产品、面料小图、品牌、编号、有效款式、备注/刺绣、面料价、加工价、附加价、运费和当地币种总价。PI 支持导出为清晰表格，导出内容与页面当前状态一致。
