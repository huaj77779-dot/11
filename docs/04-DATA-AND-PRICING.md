# 数据、价格与同步

## 单一事实源

面料、价格、款式、客户资料和 PI 必须来自结构化数据或数据库，不能在多个组件中重复写死。截图、PDF 和文档是录入依据，不是运行时第二份价格表。

## 同步规则

- 选择状态保存稳定 ID，不把显示文字当作 ID。
- PI 根据稳定 ID 映射当前名称、图片和价格。
- 删除或重命名选项时处理旧 ID，不能自动映射到无关款式。
- 修改客户档案后，历史订单保留下单快照，新订单使用最新资料。
- 面料价格修正后按具体编号验证，避免整本统一价覆盖特殊号段。

## 货币与汇率

- 基础价格保留统一基准币种和精确数值。
- 显示币种可按语言/地区推荐，但门店应能手动选择。
- 汇率来自权威 API，并记录更新时间。
- API 失败时使用最近一次成功汇率并提示时间，不允许按 1:1 静默计算。
- 面料卡、实时报价、PI、导出和历史订单使用同一汇率快照。

## 地址

- 国家支持名称和 ISO 代码搜索，代码采用 ISO 标准。
- 州/省随国家联动并支持搜索。
- 城市、邮编和详细地址在保存或导出 PI 前校验。
