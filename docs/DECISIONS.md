# 已确认产品决策

1. 品牌采用 `TailorSupply OS`。
2. 英语为主语言，中文是子语言，并适配主要欧洲语言及日语。
3. 官网采用棕色老钱风，公共页面不保留绿色主题。
4. 一件起订，不显示“衬衫 3 件起订”。
5. 公司简介、工厂品质、公司动态采用独立页面。
6. 产品为西装上衣、西裤、马甲、衬衫。
7. 款式图片单击选择、双击放大。
8. 面料筛选只显示当前品牌内真实存在的结果。
9. 面料编号显示面料册前缀，例如 `6402·33731`。
10. 量体和体态保存到客户档案并记录时间。
11. PI 只显示当前有效选择，不出现已删除或未选款式。
12. 自由备注、刺绣文字和图片同步到 PI。
13. PI 支持表格形式导出。
14. 价格按当前币种显示，所有区域使用同一汇率逻辑。
15. 工厂与流程图优先无脸构图；AI 图不能冒充真实证据。
