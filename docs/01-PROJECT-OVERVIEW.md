# 项目总览

## 项目定位

TailorSupply OS 是面向海外裁缝店、定制门店和服装品牌的白标 B2B 定制供应与数字下单系统。它将面料选择、客户量体、款式配置、实时报价、PI、生产交接和客户档案放在一个流程中。

核心价值：

- 一件起订，适合门店按客单采购。
- 西装上衣、西裤、马甲、衬衫全品类定制。
- 意大利面料与结构化面料数据。
- 门店白标展示，不突出工厂信息。
- 从面料到成衣、从客户资料到 PI 的可追踪流程。

## 目标客户

- 欧洲及全球独立裁缝店。
- Made-to-measure 定制门店。
- 需要稳定后端产能的服装品牌。
- 希望数字化记录客户尺寸与复购资料的门店。

## 品牌与内容方向

- 主品牌：`TailorSupply OS`。
- 主语言：英语；中文是其中一个子语言。
- 主视觉：深棕、胡桃木、奶油白、羊皮纸色、低饱和金色。
- 气质：老钱风、克制、专业、工艺感，不做廉价电商风。
- 图片重点：面料、裁剪、粉片划线、缝制、熨烫、质检、包装等真实工艺细节。
- 涉及人物时优先无脸构图；AI 生成图只能作为流程示意，不能伪装成真实客户证据。

## 产品边界

1. Jacket / 西装上衣
2. Trousers / 西裤
3. Waistcoat / 马甲
4. Shirt / 衬衫

系统重点服务门店下单，不是普通消费者商城。所有页面都应帮助客户更快理解面料、款式、价格、交期与下单流程。
