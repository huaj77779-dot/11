# 开发、验收与发布清单

## 功能验收

- 新客户表单为空，保存和编辑正常。
- 公制/英制切换不造成布局跳动。
- 体态、量体和时间同步到客户档案。
- 面料筛选不串品牌，所有筛选项都有结果。
- 面料编号、图片和价格对应正确。
- 单击选择、双击放大行为正确。
- 删除款式不出现在默认值、摘要、PI 或历史映射中。
- 重选面料/款式后返回 PI，数据和价格即时更新。
- 自由备注、刺绣文字和上传图案进入 PI。
- 地址国家/州省联动正常。
- PI 导出内容、币种、汇率和页面一致。

## 多语言与视觉

- 逐个切换全部语言，并搜索硬编码的中英文 UI 字符串。
- 检查动态内容、弹窗、空状态和长文本溢出。
- 公共页面没有遗留绿色主题。
- 图片无锯齿、变形、错误裁切或失效链接。
- AI 图片无明显人脸、畸形手部、假面料或错误工具动作。

## 发布前

- 运行构建并修复错误。
- 检查浏览器控制台和网络请求。
- 验证主要路由及移动端。
- 更新 `CHANGELOG.md`。
- 备份项目和关键数据。

## 重点风险

- 旧款式 ID 残留导致 PI 显示已删除选项。
- 文案写死导致漏翻。
- 价格区间被统一价格覆盖。
- 汇率 API 失败后显示错误币种。
- 图片目录存在未使用版本，增加体积。
